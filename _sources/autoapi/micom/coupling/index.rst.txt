.. py:function:: add_coupling(model, reactions, objective_variable, coupling=400, lower=0.0, exclude_variables=None)

   Adds coupling constraints to a model.

   Note that this will add a lot of constraints which can be slow for large models.

   :param model: The model to add the constraints to.
   :type model: cobra.Model
   :param reactions: The reactions to couple to the biomass reaction.
   :type reactions: iterable
   :param biomass_expression: The biomass variable to couple to.
   :type biomass_expression: Variable
   :param coupling: The coupling constraint to add (Default: 400).
   :type coupling: float, optional
   :param lower: The lower bound for the coupled reaction constraint (Default: 0.0).
   :type lower: float, optional
   :param exclude_variables: Variables to exclude from the constraint. For instance if they are associated
                             with the biomass reaction.
   :type exclude_variables: iterable

   :rtype: Nothing. The constraints are added to the model in place.


.. py:function:: add_resource_constraint(model, reactions, objective_variable, constraint=1000, lower=0.0, coupled=True, name=f'resource_constraint_{uuid4().hex[:8]}', exclude_variables=None)

   Adds a resource constraint to a model.

   :param model: The model to add the constraints to.
   :type model: cobra.Model
   :param reactions: The reactions to add the resource constraint to.
   :type reactions: iterable
   :param objective_variable: The biomass variable to couple to.
   :type objective_variable: Variable
   :param constraint: The resource constraint to add (Default: 35).
   :type constraint: float, optional
   :param coupled: If True, the resource constraint is coupled to the biomass reaction (Default: True).
   :type coupled: bool, optional
   :param name: The name of the resource constraint.
   :type name: str
   :param exclude_variables: Variables to exclude from the constraint. For instance if they are associated
                             with the biomass reaction.
   :type exclude_variables: iterable

   :rtype: Nothing. The constraints are added to the model in place.
